# Contributing

Thanks for helping. Open an issue first for anything larger than a fix.

- **Generated code** (anything headed `@generated by bin/generate`) is never edited by hand. To fix one:
  - a wrong or missing spec detail: add a patch under `openapi/patches/` with an `x-source` saying how you verified it;
  - something that's wrong everywhere: change `generator/src`.

  Then run `composer generate`.
- **The bar:** `composer test` must pass. It runs Pint, Rector, PHPStan at max level, 100% type coverage, and Pest, including the contract and documentation tests.
- **Behaviour changes** come with a test and a CHANGELOG entry.
- **Claims about SendSeven's behaviour** need a source: its docs, or a live check you describe. Add new findings to `docs/known-quirks.md`.

[AGENTS.md](AGENTS.md) has the full conventions.
